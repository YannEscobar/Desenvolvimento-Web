1. Por que praticamente todo site hoje usa HTTPS?  
   É o mais utilizado hoje já que ele é um protocolo web que permite a troca de informações de forma criptografada, protegendo dados sensíveis.

2. O que aconteceria se navegadores não interpretassem HTML?  
   Se não fosse possível ler e interpretar HTML, páginas Web não seriam possíveis de serem estruturadas.


3. Qual a maior mudança da Web 1.0 para a Web 2.0?
    A mudança da web 1.0 para a web 2.o foi a possibilidade do usuário ler e escrever e interagir com páginas Web,
dando a liberdade ao usuário para criar e interagir com conteúdo.

4. Como a IA pode mudar o desenvolvimento web no futuro?  
  Para os desenvolvedores : Vai possibilitar uma menor barreira de entrata para pessoas que não dominam ou estão estudando desenvolvimento web,
além disso a integração com IA pode ajudar a depurar códigos
oferecendo um desenvolvimento mais sólido e com menos bugs.
Para os usuários: Permite oferecer um serviço de atendimento mais eficiênte com chat bot e pesquisa por IA.
